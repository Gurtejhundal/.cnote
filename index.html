11 / FAIR QUESTIONS

wait, but…

yeah, we’ve got you.

does this mess with my source file?+

Your file stays .cpp, .py, .java, .js, .ts, .go, .rs, and so on. Notes are legal comments. The visual rendering is an editor decoration; it doesn’t rewrite the file.

will my compiler see the fancy bits?+

No. Your compiler sees normal source comments. The reading presentation only exists in VS Code.

what about line numbers and editing?+

V6 keeps the same physical line count in raw and visual states. The opener and closer have configurable boundary markers. Click back into a note to edit the original comment.

does it work offline? is there AI?+

The local editor features need no account or cloud service. .cnote parses and displays notes you write. “Explain Selected Code” inserts a template — it does not call an AI model.

can i use it for DSA and revision?+

Yes. Keep complexity notes, definitions, examples, quizzes, and checkpoints beside the implementation. Notebook includes review grades and jump-to-source navigation.

can i export my notes?+

Export the current file or workspace notes as Markdown. Notebook also supports PDF export. Snap Studio saves code and visual notes as a PNG.

does it support Markdown and JSON?+

Notes support headings, emphasis, inline code, lists, checkboxes, blockquotes, and question/answer fields. Plain JSON has no legal comments and is unsupported. Use JSONC.

is it free? does it replace my docs app?+

It’s free and MIT licensed. Use .cnote for notes tied directly to source code. Keep long-form documentation and architecture writing in your existing tools.
